# 模板工厂

手写精选库（`templates/index.js`，10 套）之外的量产管线：
把「一个 Wi-Fi 桌牌模板」拆成六个维度，机械地乘开，
再用毫米级质量闸门把印不出去的整条丢掉。
原型取自 wi-qr.com 的目录模型（维度分面 + 逐规格验收），
全部设计数据与文案本地原创，不拉远程资源。

## 六个维度

```
use     场景 10 种（住宿 / 咖啡 / 餐饮 / 美容 / 办公 / 诊所 / 接待 / 户外 / 活动 / 家用）
region  地区 5 种（新中式 / 日式 / 韩式 / 欧式 / 极简，各有签名纹样）
layout  版式 3 种（center 码居中 / split 左码右字 / stack 上字下码）
density 密度 4 档（minimal 大留白 / light 疏朗 / medium 适中 / dense 信息密）
shape   形状 5 种（1:2 / 1:1.4 / 1:1 / 1.4:1 / 2:1，对应全部打印规格）
mood    氛围 4 种（由地区派生，可叠加）
```

组合上限 10 × 5 × 3 × 4 × 5 = 3000，但「能不能印」不是组合数说了算——
同一个模板在 A4 上合格、在迷你 60×60 上可能模块细到 0.3mm。
所以打印规格是逐个筛的：`tpl.prints` 只保留 QA 全绿的规格，全绿都不剩就丢模板。

## 模块

| 文件 | 职责 |
| --- | --- |
| `templates/taxonomy.js` | 维度枚举、密度参数、地区签名、文案池 |
| `templates/qa.js` | 质量闸门：毫米级断言（码 / 字 / 对比 / 重叠 / 安全线） |
| `templates/factory.js` | 几何求解：字号 → 文字行 → 码 → 纹样，最后整体归一化到 0~1 |
| `templates/library.js` | 对外入口：精选在前、生成按页取，含 id 反查 |

## 质量闸门（templates/qa.js）

```
二维码     边长 ≥ 15mm，最坏载荷（SSID 24 + 密码 16，EC=M）单模块 ≥ 0.40mm
文字       最坏文案下不截断，自适应缩字 ≥ 原字号 62%；有效字号不破毫米下限
重叠       文字盒 × 码盒（含白色托底）、实心纹样 × 任何内容，两两不交
对比       WCAG：正文 ≥ 4.5，辅助字 ≥ 3.0，码 ≥ 7.0（对白托底）
安全线     内容距成品边 ≥ 4mm（迷你牌上自动放大边距）
装饰带     回纹 / 双线框占掉的内缩，先算纹样再排文字
比例       shape 与每个 print 的宽高比偏差 ≤ 5%
```

几何模型里最容易踩的三个坑，都在代码里有注释锚点：

1. **码是正方形，但 slot.size 相对短边**。QA 的换算必须与
   `utils/render.js` 逐字节一致（`cx→W, cy→H, size→M`），
   否则「QA 说过、渲染出来压」或反过来。
2. **panel 的 w 相对 W、h 相对 H**。想做正方形托底必须按
   `edgeMm / W` 与 `edgeMm / H` 分别换算；直接拿码边长当宽高，
   在 1:2 竖条上会画出 76×152mm 的巨块盖住整行文字。
3. **实心纹样（朱印）要在文字排完之后落位**。先放章再排字，
   章就会压在密码行上；工厂用空格子搜索（贴角优先），
   找不到空位就放弃这枚章，而不是硬塞。

## id 的自描述性

生成模板的 id 形如 `g188g1bf-000ck000a`：

```
g | 188g1bf | 000ck | 000a
  | seed    | 维度码 | 名字档 + 全局槽位
```

维度码把 shape/layout/region/density/use 打包成 5 位 36 进制，
于是 `factory.rebuild(id)` 不查缓存就能重算出与列表逐字段相同的模板。
这是编辑器冷启动的命门：用户从草稿恢复时页面缓存是空的，
`library.find(id)` 只能靠 id 反推，否则会静默回落到精选第一套。
`tools/verify-library.js` 用「空缓存下 find 命中同一条」守住这条链路。

## 名字

两字中文名，纯函数：`nameFor(slot, region, tier)`。
首字按地区分池（五池两两不相交，`poolsDisjoint()` 自检），
尾字用 `(a + 7b) mod 28` 打散（否则一页 24 条共用一个韵脚），
两条取号流（分页 / 硬条件）用不同后缀档隔离，全库 960 条零撞名。

## 用法

```bash
# 生成 24 张联络表（真实 canvas 渲染）
node tools/preview-factory.js 24 20261114

# 库验收：覆盖 / 确定性 / id 往返 / QA / 真实渲染解码（默认 3 页）
node tools/verify-library.js 8
```

页面侧：`var lib = require('../../templates/library')`，
列表用 `lib.get(offset, PAGE, hardFilters)` 翻页，
编辑器用 `lib.find(id)`。硬条件（形状 / 规格 / 场景）传给工厂，
让它在源头只长符合条件的模板，而不是先造 970 条再过滤。

## 与 main 的关系

本分支（`v2-factory`）从 `main` 的 **01:06 基线**分叉，做的是「量产能力」，
没有同步 `main` 之后那一轮**打印可读性修复**。两条线目前互有上下：

| 能力 | main | v2-factory |
| --- | --- | --- |
| 手写精选 10 套 | 有 | 有 |
| 工厂量产（3000 组合）+ QA 闸门 | — | 有 |
| 古版画花饰（`assets/ornaments`） | — | 有 |
| A6 105×148 规格 | 有 | **缺**（`PRINTS` 6 项，`1:1.4` 只映射 a4/a5）|
| 迷你 60×60 密码 ≥2.8mm | 2.88mm | **缺**（0.036 → 2.16mm）|
| 提示语空间不足自动隐藏 | 有（`render.js` 的 `hintSkipReason`）| **缺**（hint 槽位无 `optional`）|
| 竖排小字加大提亮（`slot.alpha`） | 有 | **缺** |
| 首页离屏 canvas 缩略图 | 有 | **缺**（仍是 canvas 网格 + `wx:if` 摘网格）|

断言数也不同：`main` 是 `verify-templates` 80 项，本分支 66 项；
本分支独有 `verify-library` 27 项。

合并方向是「把上表左列的修复搬进工厂版」，不是覆盖：
`render.js` 在本分支被工厂改造过（25.9KB），不能直接 copy `main` 的版本。
A6 最简单——`templates/index.js` 的 `PRINTS` 加一项，
再补 `templates/factory.js` 里 `'1:1.4': ['a4', 'a5']` 那行映射。

验收现状（本分支，2026-11-15 重跑）：
`verify-library 2` 27/27、`verify-templates` 66/66、`verify-qr` 17/17。
